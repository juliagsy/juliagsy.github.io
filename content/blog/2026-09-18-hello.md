## Writing a post

Add a file to `content/blog` named `<YYYY-MM-DD>-<slug>.md`. The date prefix keeps
the directory in chronological order and the slug becomes the URL, so this post
lives at `/tools/blog/hello`.

The frontmatter needs `title`, `date`, `tags` and `summary`. Tags have to exist in
`components/tags.json` — the build fails on one that does not, rather than quietly
dropping the post out of a filter.

## Formatting

Ordinary prose, **bold**, *italic*, `inline code`, and [links](https://arxiv.org)
all work. So do lists:

- unordered items
- with a second line
- and a third

1. ordered items
2. also work

> A blockquote, for when someone else said it better.

Code blocks keep their whitespace:

```python
def papers(topic: str) -> list[str]:
    return [p for p in fetch(topic) if p.is_interesting]
```
